# dots

Personal configuration for a **CachyOS + Hyprland + Quickshell** setup.

Captured by `sync.sh` from a live machine, so it reflects the real working
config rather than a hand-maintained ideal.

```
~/dots
├── sync.sh              pull the live system config into this repo
├── install.sh           deploy this repo onto a fresh machine
├── restore-projects.sh  re-clone the external git repos (see PROJECTS.md)
├── config/              ~/.config/*  (noise and app state stripped out)
├── home/                dotfiles + ~/.local/bin scripts
├── themes/              ~/.themes, ~/.icons, Kvantum, user fonts
├── assets/              wallpapers + avatar
├── packages/            pacman / AUR / flatpak manifests
└── patches/             local edits that were never pushed to any remote
```

## Quick start on a new machine

```bash
git clone <this-repo> ~/dots
cd ~/dots

./install.sh              # packages
./install.sh --configs    # dotfiles + config + themes + assets
./restore-projects.sh --patches   # external repos + local edits

reboot
```

## What is and isn't in here

**In** — anything you'd have to hand-rebuild: Hyprland, Quickshell, Neovim,
shell, starship, matugen schemes, GTK/Qt theming, fonts, icon theme, editor
settings, your own scripts, wallpapers, avatar.

**Out** — regenerated by apps or reinstalled by the package manager: browser
profiles, editor caches, Discord/Spotify state, Android SDK, downloaded
binaries. `sync.sh` strips these by name; the list is at the top of the file.

**Never in** — secrets. `.ssh/id_*`, `.gnupg/`, `auth.json`, `.env.local`,
`keyrings/`. Templates are written instead (`home/.ssh/config.example`,
`home/.gitconfig.example`).

**Out but documented** — the external git repos. They're listed in
`PROJECTS.md` with URLs, branches, and which ones have unpushed local edits.
Those edits are preserved as patches in `patches/`.

## The unpushed local edits

Four repos had changes that existed only in the working tree. `sync.sh` does
**not** capture them, so they're stored here as patches:

| Patch | Repo | What |
|---|---|---|
| `qylock-sddm-sh.patch` | `~/qylock` | +17 lines in `sddm.sh` |
| `matugen-theme-colorful.patch` | `~/matugen-theme-colorful` | `package.json`, `src/extension.ts`, `src/template.ts` |
| `quickshell-git-PKGBUILD.patch` | `~/quickshell-git` | local `PKGBUILD` changes |
| `nvim-config.patch` | `~/.config/nvim` | `lua/config/options.lua` |

Plus two untracked files restored by hand: `nvim-lazyvim.json`,
`nvim-transparency.lua`, and `matugen-theme-bridge/package-lock.json`.

> `~/qylock/themes-qt5/` (569M of rendered Qt5 theme assets) was untracked and
> is **not** saved here. Recreate it from `qylock/themes/` if needed.

## Re-running sync

`sync.sh` is idempotent and only reads from `~`. Run it after changing config,
then `git commit`.

```bash
./sync.sh
git status
git commit -am "sync"
```

## Layout notes

- Hyprland config is **Lua** (`hyprland.lua` + `modules/*.lua`), not the older
  `hyprland.conf`.
- Colour schemes are matugen-generated; `config/matugen/` holds the templates.
- `config/nvim` and `config/matugen/matugen-themes` are excluded from the bulk
  copy because they're git checkouts — see `PROJECTS.md`.
